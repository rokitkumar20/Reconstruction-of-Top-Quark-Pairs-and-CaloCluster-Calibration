# Top-Quark Pair Reconstruction & CaloCluster Calibration

This repository contains the source code and documentation for an academic machine learning project focused on high-energy physics data.

## Project Overview
The core objective of this project was to reconstruct top-quark pairs and calibrate CaloClusters. To achieve this, I designed and implemented a Deep Neural Network (DNN) that utilizes a custom loss function to optimize reconstruction accuracy.

## Repository Contents
* **`ttbar.ipynb`**: The Python source code containing the data pipeline, DNN architecture, custom loss function implementation, and model evaluation.
* **`1820021_RAML(Documentation).pdf`**: The comprehensive project report detailing the theoretical methodology and final results.

## Technologies & Core Libraries
* **Deep Learning & ML:** TensorFlow, Keras, Scikit-learn
* **Data Processing:** Pandas, NumPy, Awkward Array
* **High-Energy Physics Tools:** Uproot, Vector
* **Data Visualization:** Matplotlib
